# ⚓ Day Shapes Detection (COLREG-72) - Отчет о проекте

## 1. Цель проекта
Автоматизация распознавания дневных навигационных знаков (Day Shapes) согласно МППСС-72 (COLREG-72) для определения навигационного статуса судов.

## 2. Методология решения
Задача была разбита на два этапа:
1. **Computer Vision (YOLO11n):** Детекция отдельных геометрических примитивов (шары, ромбы, цилиндры, конусы).
2. **Логический классификатор:** Скрипт постобработки `inference_pipeline.py`, который анализирует комбинации найденных знаков.

## 3. Подготовка данных (Синтетический датасет)
Был разработан скрипт `generate_day_shapes.py` для генерации 2000 изображений.
- Разрешение: 1024x1024.
- Классы: `ball`, `diamond`, `cylinder`, `cone_up`, `cone_down`.
- Добавлены сложные фоны, шумы и аугментации.

## 4. Обучение модели
- **Модель:** YOLO11n.
- **Параметры:** `imgsz=1024`, `epochs=50`.
- **Результаты:** mAP50 0.995 на синтетических данных.

## 5. Итоговая логика приоритетов
Скрипт `inference_pipeline.py` ограничивается 6 строгими классами COLREG:
- `NUC`, `RAM`, `CBD`, `Fishing`, `Sailing`, `Power-driven`.
