# ⛵ Sailboat Binary Classifier - Отчет о проекте

## 1. Цель проекта
Разработка и обучение модели глубокого обучения для задачи бинарной классификации изображений: определение, является ли судно на фотографии парусником (классы: `sailboat` и `not_sailboat`).

## 2. Исходные данные
- Исходный датасет представлял собой набор изображений судов в формате YOLO (10 классов: Aircraft Carrier, Bulkers, Car Carrier, Container Ship, Cruise, DDG, Recreational, Sailboat, Submarine, Tug).
- Присутствовал сильный дисбаланс классов: всего 358 парусников против 8330 остальных типов судов.

## 3. Подготовка датасета
Для решения задачи бинарной классификации и устранения дисбаланса был разработан скрипт `prepare_data.py`, который выполнил следующие шаги:
1. **Извлечение объектов (Кроппинг):** Из полных изображений по координатам YOLO-разметки были вырезаны отдельные суда.
2. **Формирование бинарных классов:**
   - **`sailboat`**: взяты все 358 доступных кропов парусников.
   - **`not_sailboat`**: сформирована случайная выборка из остальных 9 классов (не более 160 изображений из каждого класса), чтобы суммарно получить 1440 изображений.
3. **Разбиение выборки:** Полученный датасет был разделен на три независимые выборки:
   - **Train (70%)**
   - **Valid (20%)**
   - **Test (10%)**

## 4. Архитектура модели и процесс обучения
- **Базовая модель:** В качестве основы использовалась архитектура **EfficientNet-B0**, предварительно обученная на наборе данных ImageNet.
- **Слой классификации:** Финальный полносвязный слой сети был заменен на новый с двумя выходами.
- **Гиперпараметры:** Оптимизатор Adam, Learning Rate = 0.001, Batch Size = 32, Epochs = 15.

## 5. Результаты тестирования
**Финальные метрики:**
- **Accuracy (Точность):** 100%
- **Precision / Recall / F1-Score:** 1.00 для обоих классов.
